# vue2-study

## 创建项目 Node版本 18lts nvm管理版本 
```bash
nvm install 18
nvm use 18
nvm current

npm install -g nrm

npm install -g @vue\cli

vue create vue2-study

cd vue2-study

npm install

npm run serve
```

npm install
